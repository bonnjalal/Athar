# Static Assets (`app/static`)

## Overview
Houses static client-side resources served by Flask for the Athar dashboard interface, including JavaScript modules, Wikimedia Codex styling, and visual brand assets.

## Subdirectories & Boundaries
- [js](./js/README.md): Client-side JavaScript modules handling dynamic Chart.js visualizations, real-time activity filters, and CSV data export functionality.
- `css`: Wikimedia Codex and UI layout stylesheets (static styling assets).
- `images`: Graphic assets, icons, and logos.
